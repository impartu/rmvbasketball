Genesis Bot Privacy Policy

Effective date: October 1, 2026

  • Genesis Bot uses Google's YouTube Data API only to list videos and update the existing video descriptions on the 5onfive Genesis YouTube channel, as authorized by that channel's owner.
  • It does not access any other Google data, and it does not collect data from any other users.
  • It does not sell, share, or transfer data to third parties, and it does not use data for advertising.
  • The OAuth sign-in token used to access the channel is stored privately and used only for the purpose described above. The channel owner can revoke access at any time at myaccount.google.com/permissions.
  • Genesis Bot's use of Google user data follows the Google API Services User Data Policy, including the Limited Use requirements.
